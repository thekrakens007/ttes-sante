MISE A JOUR LOGO - TTES-ICG SANTE

Copier le contenu de ce dossier dans la racine de ttes-icg-sante-frontend en conservant les chemins.

Fichiers principaux:
- public/images/logo/logo.svg
- public/images/logo/logo-dark.svg
- public/images/logo/logo-icon.svg
- public/images/logo/auth-logo.svg
- public/favicon.ico
- public/images/favicon.ico

Les 4 templates HTML inclus adaptent le header, la sidebar et la page de connexion au nouveau format du logo.

Après copie:
  npm install   (si node_modules n'existe pas)
  npm start

Puis ouvrir l'application et faire Ctrl+F5 pour forcer le rechargement des assets.
